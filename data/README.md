# 伊予鉄道 市内電車 時刻表データセット

このディレクトリは、伊予鉄道 市内電車（路面電車）の時刻表・路線データを構造化したものです。

## 出典
- **時刻表**: 伊予鉄道「市内電車時刻表」2023年11月1日改正版（公式PDF）
- **路線図**: 伊予鉄道「市内電車路線図」（公式PDF）
- **運賃**: 2026年4月1日改定（大人 現金250円 / IC・みきゃんアプリ230円）

時刻・運賃・系統は事実情報であり、公式資料を元に独自に構造化したものです。正確性は公式情報を参照してください。

## ファイル構成

| ファイル | 役割 | データ区分 |
|---|---|---|
| `stops.json` | 電停マスタ（全29電停） | 一次（路線図由来）※座標は概算 |
| `routes.json` | 系統定義（5系統の電停順・色・運行特性） | 一次 |
| `timetable_route1.json` | ①番 環状線（時計回り）の便ごと時刻 | 一次（時刻表由来） |
| `timetable_route2.json` | ②番 環状線（反時計回り） | 一次 |
| `timetable_route3.json` | ③番 松山市駅線（両方向） | 一次 |
| `timetable_route5.json` | ⑤番 JR松山駅前線（両方向） | 一次 |
| `timetable_route6.json` | ⑥番 本町線（両方向・平日のみ） | 一次 |
| `segments.json` | 中間電停の補間定義 | **派生（推定値）** |

## データモデルの考え方

### 便ごとの全電停時刻
各系統の時刻表は「便（trip）」単位で持ち、各便は停車する電停の発車時刻を `電停id: "H:MM"` の形で保持する。
区間便（古町止め等）は通らない電停のキーを含めないことで表現する。

### 一次データと派生データの分離
- **一次データ（timetable_route*.json の記載時刻）**: 公式PDFに印字された時刻。変更しない。
- **派生データ（segments.json）**: 公式PDFに時刻が無い中間電停を補間するための推定値。修正はここだけで完結する。

### 日中便の展開
日中は公式PDF上「この間○分毎」と省略されている。各 timetable の `daytime_pattern` に
`first_departure` / `last_departure` / `interval_min` / 起点からの `segment_offsets_from_origin` を持つので、
実装側でこれを展開して個別便を生成する。

### 土日祝の扱い
- 平日ダイヤを基本とし、土日祝（および振替休日）に運休する便は `saturday_holiday_suspended: true`。
- ⑥番 本町線は **全便が土日祝運休**（`weekday_only: true`）。
- **年末年始（12/30〜1/3）は祝日扱い**。

## 検証
`validate.py` で JSON 妥当性・時刻単調増加・電停id重複の自動チェックができる。

## データ照合ステータス（2026-05-29 完了）
全系統を、利用者がPDFからコピー&ペーストしたテキストおよびスクリーンショットと突き合わせて照合済み。
- ①〜⑥番すべての各駅時刻が原本と一致することを確認
- 照合過程で発見・修正した点:
  1. ②番 夜間便: 全区間便と古町止め便の割り当て（N3↔N4）を修正
  2. ⑤番 道後温泉発: 土日祝運休便の見落とし（8:37発=O13）を追加
- 土日祝運休便（網掛け）の最終確定:
  - ③番: 道後温泉7:27発(I6)、松山市駅7:51発(O8)
  - ⑤番: 道後温泉8:26発(O11)・8:37発(O13)、JR松山駅前7:51発(I8)・8:00発(I9)
  - ①②番: 運休便なし（全曜日運行）
  - ⑥番: 全便が土日祝運休（平日のみ運行）

## 要検証事項（実装前に確認推奨）
1. 電停の緯度経度（`requires_coord_verification: true`）— 現状は概算。現在地→最寄り電停判定用に実測へ差し替え推奨。
2. 中間電停の所要時間（segments.json）— 実乗車での補正が望ましい。
